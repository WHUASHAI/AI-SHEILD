# AI SHIELD: Client Discussion Guide

## 1. What is AI SHIELD?

**AI SHIELD** is a centralized platform designed to detect AI-generated content. As fake media becomes harder to distinguish from reality, AI SHIELD provides a single dashboard where users can upload different types of files to verify if they are real, original, or digitally created by AI.

---

## 2. Detection Features

Below is a simple breakdown of every scanning feature, explaining what it does, its technical limitations, and the common problems you might encounter.

### A. Text AI Detection
**What it is used for:**
When a user submits an essay or article, the system reads and analyzes the writing style. It is used to figure out whether the text was written naturally by a human or generated by an Artificial Intelligence.

**Limitations:**
* **Word Count Constraints:** You can only submit text that falls under a specific word limit. Submissions that are too long will not be accepted by the system.

**Problems:**
* **The "False Positive" Problem:** The system looks for robotic, highly predictable writing patterns. If a human naturally writes in a very strict or repetitive way, the system might accidentally flag their human writing as AI-generated.
* **AI Source Confusion:** There are dozens of AI platforms available today (like ChatGPT, Claude, and Gemini). Because they all generate text similarly, the system might successfully detect that a text is AI, but it will often struggle to accurately guess *which specific* AI platform created it.

### B. Plagiarism Detection
**What it is used for:**
When a user submits text, the system takes the sentences and searches the entire internet. It is used to see if those exact sentences were copy-pasted from articles or websites that are already published online.

**Limitations:**
* **Search Dependency:** The system can only find matches on websites that are public and easily searchable. It cannot check against private documents, offline books, or brand-new articles that search engines haven't discovered yet.

**Problems:**
* **Original Source Confusion:** The internet is full of people copying each other. If the system detects that a paragraph was copied, it might point you to a secondary website that copied the text, rather than finding the very first person who originally wrote it. 

### C. Image AI Detection
**What it is used for:**
When a user uploads a picture, the system scans the image to see if it was completely created by an AI image generator or if it was heavily edited using digital tools.

**Limitations:**
* **File Size Constraints:** Image uploads must be standard image types (like JPEG or PNG) and are limited to a maximum of **50MB** per file.

**Problems:**
* **Evolving Technology:** AI image generators are constantly improving and looking more realistic every day. Because the technology moves so fast, a brand-new AI generator might create an image so perfect that our system misses it until our detectors are updated to catch the new tricks.

### D. Video Analysis
**What it is used for:**
When a user uploads a video, it would take too long to watch every single second. Instead, the system automatically takes quick snapshots (called keyframes) throughout the entire video. It analyzes these snapshots to see if the video was AI-generated.

**Limitations:**
* **Size and Length Constraints:** Video files can be very large, so uploads are strictly limited to a maximum of **2GB** in file size and cannot be longer than **30 minutes**.

**Problems:**
* **Sampling Gaps:** Because the system relies on taking quick snapshots, there are gaps in between the photos. If a video has a very brief, split-second AI glitch that happens exactly between two snapshots, the system might miss the fake completely.

### E. Deepfake & Face-Swapping Detection
**What it is used for:**
When a user uploads a photo or video containing people, this feature specifically zooms in on the faces. It checks for unnatural facial movements, weird blending, or mismatched lip-syncing to determine if a person's face was digitally swapped or altered.

**Limitations:**
* **Requires Clear Faces:** This tool only works if there is a clear, visible human face. If you upload a cartoon, a picture of a mountain, or a face that is hidden, the system simply cannot scan it and will return a zero score.

**Problems:**
* **Lighting and Quality Issues:** If a completely real video is extremely dark, blurry, or very low quality, the system might struggle to analyze the face properly. This poor quality can confuse the detector, leading to inaccurate results.

---
*Summary for Client:* AI SHIELD is an easy-to-use platform to check for digital forgery across all major media types. While it is a very helpful tool, users should be aware of the file limits and understand that false alarms can occasionally happen due to the nature of AI technology.
